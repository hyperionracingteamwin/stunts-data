Install & restore Windows

Extract BACK_TO_THE_FUTURE_STUNTS into your Stunts folder. Run INSTALLER.bat in Windows. To restore your previous files, run DESINSTALLER.bat.

Install & restore Manual file copy · Stunts 1.1 VGA

Extract the ZIP, then copy CARBIRD.RES, STBIRD.3SH, STDABIRD.VSH and STDBBIRD.VSH into your Stunts 1.1 VGA game folder. Back up previous BIRD files and move any competing STBIRD.P3S, STDABIRD.PVS and STDBBIRD.PVS out of the game folder. Read LIRE_MOI.txt for details.

To restore an earlier version, remove the four BIRD files and put your backed-up files back. The ZIP also contains LIRE_MOI.txt, technical previews and development sources.
