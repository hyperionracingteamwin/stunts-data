# 04 · Plymouth Superbird NASCAR — V08

NASCAR edition and custom cockpit by **Alain il Professore · Hyperion Racing Team**.
Original 3D base credited to **Alan Rotoi** in the supplied development notes.

[Download the complete pack](Plymouth_Superbird_NASCAR_V08.zip) · [VGA cover (PNG)](cover.png) · [VGA bitmap (BMP)](cover.bmp)

The ZIP is the creator’s supplied V08 archive, preserved byte for byte. It contains the four BIRD game resources, technical previews, source files, development notes and a documented simulated torque curve.

## Installation

Requires your own Stunts 1.1 VGA installation. Extract the archive and copy these four files into the game folder:

- `CARBIRD.RES`
- `STBIRD.3SH`
- `STDABIRD.VSH`
- `STDBBIRD.VSH`

Back up previous BIRD files first. Move any competing `STBIRD.P3S`, `STDABIRD.PVS` and `STDBBIRD.PVS` outside the game folder. To restore, remove the four installed files and restore your backups. See the supplied `LIRE_MOI.txt` for the original technical notes.
