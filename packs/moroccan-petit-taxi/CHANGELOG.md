## 1.0.0 · 2026-11-05

### Français

- Première version du pack de distribution Stunts 1.1 VGA pour `P205`. Le suffixe de téléchargement `(1)` a été retiré des quatre noms pour que le jeu reconnaisse les fichiers.
- Quatre ressources d’origine conservées à l’identique et vérifiées par SHA-256.
- Installation et désinstallation réversibles sous Windows et DOS, avec sauvegarde des fichiers remplacés.
- Documentation FR/EN et vignette pixel art VGA pour le garage.

### English

- First Stunts 1.1 VGA distribution pack for `P205`. The four source filenames lost the download suffix `(1)` to match the game’s required filenames.
- Preserved all four original resources byte for byte and verified their SHA-256 checksums.
- Added reversible Windows and DOS installation with backups for replaced files.
- Added FR/EN documentation and a VGA pixel-art cover for the garage.
